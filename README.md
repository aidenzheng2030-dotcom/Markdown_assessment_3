# Your Command Line Cheatsheet ! 🖱️
## The only cheat sheet you'll need ! ⌨️

`
File & Directory Commands
`

👨‍💻 - The command **ls** will *list your directory files.*

💽 - The command **cd ..** will let you *go back to a directory.*

🖳 - The command **cd <folder>** will let you *change to another directory.*

💾 - The command **pwd** will *show your current directory.*

1. The command **mkdir <name>** will let you create a new folder.

My Example:

```
mkdir folder1
```
---
2. The command **rmdir <name>** will let you remove an empty folder.

My Example:

```
rmdir folder1
```
---
3. The command **clear** will let you clear the terminal screen.

My Example:

```
clear
```
